# Italienisch-Vokabeltrainer

Ein browserbasierter Italienisch-Vokabeltrainer mit eingebautem Vokabelstapel. Keine Installation, kein Server und keine externen Abhängigkeiten nötig.

## Bedienung

- **Enter / Return:** Antwort aufdecken.
- **Enter / Return erneut:** Als gewusst markieren und aus dem aktiven Stapel entfernen.
- **Leertaste:** Nicht gewusst; die Vokabel bleibt im Stapel und wird später erneut zufällig abgefragt.

Die Anzeige zeigt die noch im Stapel befindlichen und die bereits gewussten Vokabeln. Der Lernfortschritt wird lokal im jeweiligen Browser gespeichert.

## Veröffentlichung mit GitHub Pages

1. Neues Repository auf GitHub erstellen.
2. `index.html` und optional `README.md` in das Hauptverzeichnis des Repositorys hochladen.
3. Unter **Settings → Pages → Build and deployment** bei **Source** `Deploy from a branch` wählen.
4. Als Branch `main` und als Ordner `/ (root)` auswählen und speichern.
5. Die veröffentlichte Adresse wird unter **Settings → Pages** angezeigt; normalerweise `https://BENUTZERNAME.github.io/REPOSITORYNAME/`.

Alternativ `index.html` lokal per Doppelklick im Browser öffnen.

**Hinweis:** Der Lernfortschritt wird im Browser gespeichert, nicht mit GitHub synchronisiert. Auf anderen Geräten beginnt er separat.
